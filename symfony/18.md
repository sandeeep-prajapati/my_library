# Safe Upgrade Strategy for Symfony/Pimcore/Akeneo Customizations

Upgrades are safer when customizations are isolated, inventoried, and tested.

## 1) Pre-Upgrade Checklist

- Inventory all overrides/decorators/subscribers.
- Mark risky ones: internal/private service dependencies.
- Freeze schema-changing work during upgrade window.

## 2) Upgrade Flow

1. Update dependencies in branch.
2. Rebuild container and fix deprecations.
3. Run full test suite.
4. Run smoke tests on critical workflows.
5. Compare performance and logs.

## 3) Deprecation-Driven Migration

Treat deprecations as roadmap. Fix on current version before major jump.

## 4) Contract Protection

Maintain:
- API response snapshots
- critical DB migration checks
- business workflow end-to-end tests

## 5) Common Mistakes

- Relying on undocumented internal services.
- Large upgrade + feature release in same deploy.

## 6) Best Practices

- Keep extension points explicit.
- Use staged rollout and fast rollback plan.
- Maintain upgrade notes per customization.

## 7) Quick Recap

Safe upgrades are mostly preparation discipline: isolate custom code, test contracts, and deploy gradually.
