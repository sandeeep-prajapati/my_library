# Clean Third-Party API Integration (Adapters, DTOs, Services)

Never spread vendor SDK calls across your codebase. Wrap external APIs behind adapters.

## 1) Clean Integration Stack

- `Client` interface (your contract)
- Adapter implementation (SDK/HTTP details)
- DTOs for request/response payloads
- Application service consuming interface only

## 2) Example Shape

```php
interface ShippingGateway
{
    public function createLabel(CreateLabelRequest $request): CreateLabelResponse;
}
```

Adapter handles retries, auth, and response mapping.

## 3) Reliability Essentials

- Timeouts and retry policy
- Circuit breaker/fallback
- Correlation IDs in outbound requests

## 4) Common Mistakes

- Returning raw vendor response arrays.
- No anti-corruption layer, so vendor model leaks everywhere.

## 5) Best Practices

- Validate DTOs at adapter boundary.
- Map vendor errors into domain-specific exceptions.
- Add integration tests with API mocks/sandbox.

## 6) Quick Recap

Adapters + DTOs isolate external churn and keep your core architecture stable.
